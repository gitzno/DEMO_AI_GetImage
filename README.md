# DEMO OCR AI VISION ON TAG SHOE
## By gitzno
 
🔗 Link truy cập: https://demoai.tdmk.vn/

🛠 Hướng dẫn trải nghiệm nhanh:<br/>
Bước 1: Anh/chị truy cập link trên (dùng điện thoại hoặc máy tính đều được).<br/>
Bước 2: Tải lên một vài bức ảnh chụp tem giày thực tế.<br/>
Bước 3: Hệ thống AI sẽ tự động khoanh vùng, bóc tách dữ liệu (Size/Product Code) và tổng hợp thành dạng bảng (Table).<br/>
Bước 4: Anh/chị bấm chọn tính năng 'Xuất file' để tải về dữ liệu mẫu dưới dạng file CSV/Excel.<br/>
💡 Lưu ý nhỏ về hạ tầng: Bản Demo này được tôi dựng nhanh trên môi trường web test để tiện thao tác từ xa. Khi triển khai chính thức tại nhà máy, hệ thống sẽ được đóng gói chạy Offline trực tiếp trên Workstation nội bộ của xưởng. Lúc đó tốc độ xử lý sẽ là Real-time (tức thời) và độ ổn định đạt mức tuyệt đối 24/7.
